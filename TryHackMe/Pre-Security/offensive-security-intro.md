# Room: Offensive Security Intro
**Path:** Pre-Security  
**Date:** 12/03/2026  
**Difficulty:** Easy

---

## Summary
Introduction to the concept of offensive security through a simulated banking environment. The goal was to think like an attacker and find exposed information by exploring the application.

---

## What I Learned
- Offensive security is about understanding how attackers think in order to better defend systems.
- Web applications can expose sensitive information through poorly protected URLs.
- Navigating an application manually can reveal unintended access points.

---

## Process
1. Explored a simulated banking web application.
2. Used the terminal to discover hidden or unlinked URLs within the app.
3. Identified a target URL and accessed a restricted section.
4. Navigated to the deposits section and completed the simulated attack scenario.

---

## Tools Used
- Linux Terminal
- Web Browser
