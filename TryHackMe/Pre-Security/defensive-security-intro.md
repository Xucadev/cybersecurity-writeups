**Path:** Pre-Security  
**Date:** 12/03/2026  
**Difficulty:** Easy

---

## Summary
Introduction to defensive security through a simulated SOC (Security Operations Center) environment. Assumed the role of a junior SOC analyst tasked with detecting and stopping an active attack on a simulated bank.

---

## What I Learned
- Defensive security focuses on monitoring, detecting, and responding to threats before or during an attack.
- SOC analysts work with monitoring dashboards to identify anomalous traffic patterns.
- Attackers often target administrative URLs as entry points.
- Firewall rules are a frontline control for blocking malicious actors.

---

## Process
1. Reviewed active alerts on a SOC monitoring dashboard.
2. Identified a suspicious IP address generating anomalous traffic.
3. Analyzed the attacker's access attempts to determine the targeted resource — an admin URL.
4. Implemented a firewall rule to block the malicious IP and stop the attack.

---

## Tools Used
- SOC Monitoring Dashboard (simulated)
- Firewall Rule Manager (simulated)
